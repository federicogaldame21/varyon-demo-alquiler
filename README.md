# Mano Firme · Alquiler de herramientas — demo de Varyon

Sistema web para un comercio de alquiler de herramientas: stock, contratos, garantías y devoluciones con daños.

Demo navegable con datos ficticios, hecha por [Varyon](https://varyon.com.ar).
Caso de estudio completo: https://varyon.com.ar/proyectos/alquiler

## Cómo verla en tu compu

Es un sitio estático (HTML, CSS y JavaScript, sin dependencias). Abrí `index.html` en el navegador,
o levantá un servidor local:

```bash
npx serve .
```

## Publicación

Se publica en Cloudflare Pages directo desde este repo: sin comando de build y con `/` como carpeta de salida.
